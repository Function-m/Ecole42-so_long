## 1. 프로젝트 개요

본 프로젝트는 MiniLibX 라이브러리를 사용하여 제작된 간단한 2D 게임입니다. 플레이어는 맵에 흩어져 있는 모든 수집 아이템을 획득하고, 탈출구를 찾아 맵을 탈출해야 합니다.

## 2. 필수 파트

* C 언어로 작성되었습니다.
* Norm 규정을 준수합니다.
* 예상치 못한 종료(세그멘테이션 오류, 버스 오류 등) 없이 정상적으로 동작합니다.
* 할당된 메모리는 모두 해제됩니다.
* Makefile을 통해 컴파일하며, `-Wall`, `-Wextra`, `-Werror` 플래그를 사용합니다.
* 프로그램은 `.ber` 확장자를 가진 맵 파일을 인자로 받습니다.
* MiniLibX 라이브러리를 사용합니다.
* 플레이어는 W, A, S, D 키를 사용하여 상, 하, 좌, 우로 이동합니다. (또는 ZQSD, 화살표 키 사용 가능)
* 플레이어는 벽을 통과할 수 없습니다.
* 이동할 때마다 이동 횟수가 쉘에 표시됩니다.
* 2D 시점(탑다운 또는 사이드뷰)을 사용합니다.
* 창을 통해 이미지를 표시합니다.
* 창 관리(창 전환, 최소화 등)가 원활하게 이루어집니다.
* ESC 키 또는 창의 닫기 버튼을 누르면 창이 닫히고 프로그램이 종료됩니다.
* 맵은 벽, 수집 아이템, 빈 공간으로 구성됩니다.
* 맵은 '0'(빈 공간), '1'(벽), 'C'(수집 아이템), 'E'(탈출구), 'P'(플레이어 시작 위치) 문자로 표현됩니다.
* 맵은 반드시 1개의 탈출구, 최소 1개의 수집 아이템, 1개의 시작 위치를 포함해야 합니다.
* 맵은 직사각형 형태여야 합니다.
* 맵은 벽으로 둘러싸여 있어야 합니다.
* 맵에 유효한 경로가 있는지 확인합니다.
* 맵 파일에 오류가 있는 경우, "Error\\n"과 함께 오류 메시지를 출력하고 프로그램을 종료합니다.

## 보너스 파트

* 플레이어가 적에게 닿으면 패배합니다.
* 스프라이트 애니메이션이 추가되었습니다.
* 이동 횟수가 쉘 대신 화면에 표시됩니다.

## 구현 내용

### 게임 플레이

플레이어는 맵에 있는 모든 수집 아이템을 모아야 하며, 탈출구를 통해 맵을 탈출하는 것이 목표입니다. W, A, S, D 키를 사용하여 플레이어를 이동시키고, 이동 횟수는 화면에 표시됩니다. 벽을 통과할 수 없으며, 적에게 닿으면 게임에서 패배합니다.

### 그래픽 관리

MiniLibX 라이브러리를 사용하여 창을 생성하고, 맵과 캐릭터, 아이템, 적 등을 이미지로 표시합니다. 창 관리 기능이 구현되어 있으며, ESC 키나 창 닫기 버튼을 통해 게임을 종료할 수 있습니다. 스프라이트 애니메이션을 통해 캐릭터와 적의 움직임을 더욱 생동감 있게 표현했습니다.

### 맵 구성

맵은 텍스트 파일 형태로 주어지며, '0', '1', 'C', 'E', 'P' 문자를 사용하여 맵의 요소들을 표현합니다. 맵은 직사각형 형태여야 하며, 벽으로 둘러싸여 있어야 합니다. 맵 파일에 오류가 있는 경우, 오류 메시지를 출력하고 프로그램을 종료합니다.

## 사용법

1.  **컴파일:**
    ```bash
    make
    ```
2.  **실행:**
    ```bash
    ./so_long [맵 파일.ber]
    ```
    예시:
    ```bash
    ./so_long maps/map1.ber
    ```
3.  **조작:**
    * 이동: W, A, S, D 키
    * 종료: ESC 키 또는 창 닫기 버튼

**참고:** 보너스 기능은 `bonus` 규칙을 사용하여 컴파일할 수 있습니다.
```bash
make bonus
```

## 주의사항

* 맵 파일은 반드시 `.ber` 확장자를 가져야 합니다.
* 맵은 직사각형 형태여야 하며, 벽으로 둘러싸여 있어야 합니다.
* 맵은 1개의 탈출구, 최소 1개의 수집 아이템, 1개의 시작 위치를 포함해야 합니다.
* 맵 파일에 오류가 있는 경우, 프로그램이 정상적으로 실행되지 않을 수 있습니다.
